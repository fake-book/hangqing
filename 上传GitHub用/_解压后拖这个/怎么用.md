# 行情表 · 怎么用

放这个文件夹里，四样东西：

| 文件 | 干什么 |
| --- | --- |
| **行情.html** | ★ 双击就开。你要看的表就是它 |
| **刷新行情.bat** | ★ 双击，抓最新行情（约 1 分钟），自动打开表 |
| 快刷测试.bat | 只抓前 10 页，5 秒出结果，网络不稳时先用这个 |
| **手机上看.bat** | ★ 双击，让手机也能看这张表 |
| 行情.csv | Excel 能开，想自己算就用它 |
| data/ | 每次抓的历史快照，用来算「较上次」变动。别删 |

---

## 一、每天怎么用

1. 双击 **刷新行情.bat**
2. 等 1 分钟，表自己弹出来
3. 最上面一排卡片就是你家那几个品种的今日价

**不用天天刷。** 一周刷一两次就够——药材价格不是股票，不会一天变十次。
真要看某天的变化，看表里「较上次」那一列，红的是涨，绿的是跌。

---

## 二、表怎么看

**顶部六张卡片** —— 自家品种·亳州今日
菊花（杭菊 / 贡菊 / 亳菊）、玫瑰、金银花，各自今日价 + 年涨跌。
这是你爸最需要的一屏，别的都是背景。

**下面大表** —— 2356 条全市场行情

| 列 | 意思 |
| --- | --- |
| 品名 | ★ 带星的是你家主营，置顶 |
| 规格 | 同一个品种不同等级，价格差很多，别混着比 |
| 市场 | 亳州 / 安国 / 荷花池 / 玉林，四个大药市 |
| 价格 | 元/公斤。罗汉果是元/个、蛤蚧元/对 |
| 走势 | 平 / 慢 / 快 —— 商家对后市的态度 |
| 周 / 月 / 年 | 涨跌幅，红涨绿跌 |
| 较上次 | 跟你上次刷新比，动了多少 |

**搜索框**：打「菊花」「贡菊」「黄芪」都行，规格产地也搜得到。
**只看 ★ 重点**：过滤掉不相干的，只留你家那几样。
**点表头**：按价格、按月涨跌排序。想看「谁涨得最凶」就点「月」。

### 点一行，看它这一年的价格曲线

**点表格里任意一行**，会弹出一张曲线图：

- 上面一排数字：最新价、这一年涨了多少、涨跌幅、最高、最低、**距最高/离最低**、以及一个**价格位置条**
- 中间是曲线，红色=这一年涨了，绿色=跌了
- 图表上一排胶囊是**同一个品种的不同规格**，点一下换规格（比如菊花能切 亳菊/黄山贡菊/杭菊/杭饼菊/七月菊/太阳花/祁菊）
- 底下四个按钮换时间范围：近 1 月 / 近 3 月 / 近半年 / 近一年
- 鼠标在图上移动，会跟着显示具体那天的价格，两位小数

**那条「价格位置」是给你做卖货判断用的：**

看的是`现在这个价，在最近这段时间里算贵还是便宜`。左边绿是区间最低、右边红是区间最高，金色小竖线是现在的位置。

| 显示 | 意思 |
| --- | --- |
| 低位 / 偏低 | 这价在一年里算便宜，卖了亏 |
| 中间偏下 / 偏上 | 就是这么个价，谈不上贵贱 |
| 偏高 | 离这一年最高只差一点了，**该考虑出** |

再配合「距最高 −1.61%」这种数字一起看：离最高只差 2%，就说明有人在这个价接得住，你想卖就卖得掉；离最高差 40%，说明现在压根没人出这个价。

**为什么只有一年，没有十年：**

我试了康美、中药材天地网、药通网、中国药材市场网，还有康美的指数站，一共二十几个接口。

单品种的逐日历史价格，这些站**免费只放最近一年**，十年以上的完整数据是他们的付费产品（天地网的品种页直接挂「登录后查看」，药通网要登录 session）。网页时光机（web.archive.org）在国内也打不开。

所以图上写清楚了：**站方免费只开放最近一年**。

真想要十年，只有两条路：
1. **问家里或者常来往的同行，有没有天地网/康美的会员账号**。做批发几十年的人，很可能有。有账号的话把账号给我，脚本改几行就能抓十年。
2. **从今天起每天存着**。现在这个表每刷一次就在 `data/` 里留一份带时间戳的快照，攒上三年就是三年的真实成交记录，比任何二手数据都值钱——因为那是你自己市场的价。

**图上两种形状要分清：**

| 形状 | 意思 |
| --- | --- |
| 一条平线，几个月不动 | 这货没人抢，也没人抛，就是这个价挂着 |
| 台阶一样一格格上/下 | 真的在调价，一格就是一毛两毛的让 |

**目前预载了 786 个品种、1064 条曲线**（表格里 772 个品种，其中 614 个点进去有曲线）。剩下的 158 个品种康美没收录历史，标「（没曲线）」。

按行算更准：**2368 行里 66.5% 点进去直接出曲线**，23.8% 是「有这品种、没这规格」，9.7% 是整个品种没数据。

**品名后面那个括号，是在告诉你点进去会发生什么**：

| 括号 | 你点进去会怎样 |
| --- | --- |
| **（有曲线）** | 直接出曲线，放心看 |
| **（没这规格）** | 这个品种有曲线，但你这一行的**规格**它没记（比如天麻「野统」）。点进去会让你从它能查的几个规格里挑一个 |
| **（没曲线）** | 这个品种整个都没有历史价格数据，点进去不会出图 |

「没这规格」和「没曲线」差着大事：前者是这个货有历史、只是叫法不一样；后者是整条品种都没数据。

**为什么会有「没这规格」——国家其实有统一标准**

商务部 **SB/T 11173-2016《中药材商品规格等级通则》**（2017-05-01 实施，现行）把两个词定死了：

> **规格**：区分不同交易品类的依据，一般是**非连续性特征**（野生 / 家种、个子 / 切片、不同产地）
> **等级**：一个规格下区分品质的依据，一般是**连续性指标**（一等 / 二等 / 三等、统货）

**天地网把「规格＋形态＋等级＋产地」四样压在一个字符串里**（野统 较广 = 野生规格 + 个子形态 + 统货等级 + 产地较广）；
**康美只记「等级」一样**（一等 / 二等 / 统）。

所以对不上不是名字乱，是**录入的字段数不同**。而且**康美自己就是这套标准的起草方之一**（参与人参、西洋参、冬虫夏草、白芍、**菊花**等 14 种的分品种标准制定）。

详细的对照表和拆解规则写在 `规格等级-统一叫法.md` 里。

### 规格对不上，弹窗会明说

大表来自**中药材天地网**，曲线来自**康美中药网**，是两个站。同一个品种，两边记的规格不是一套：

- 天地网写「天麻 野统 较广」，康美只有「一等 / 二等 / 三等 / 统」
- 天地网写「三七 20头春七」，康美写「20头」
- 天地网写「菊花 贡菊朵菊统」，康美写「黄山贡菊」

**原则：对不上就直说，绝不拿别的规格顶替。**

点一行之后会碰到三种情况：

| 你看到的 | 什么意思 |
| --- | --- |
| 直接出曲线，没有黄条 | 规格对上了，放心看 |
| 出曲线 + 上面一条黄条 | 叫法不一样，这是最接近的一个。看走势可以，**别把这条线的价钱直接当成你那一行** |
| 不出曲线，让你选规格 | 康美压根没这个规格（比如「野统」）。中间列出它能查的全部规格，点一个看 |

黄条里还有一种是**市场不同**：表格那一行是玉林 / 安国的报价，曲线永远是亳州的。同一个品种两个市场差几块钱，是常事。

**为什么宁可让你多点一步，也不自动凑：** 天麻「野统」600 一公斤，「统」100 一公斤，差六倍。自动凑上去，你看到的曲线就不是你那一行的货了。

## 三、数据从哪来

- **中药材天地网**（zyctd.com）—— 四大药市公开报价 + 周月年涨跌
- **康美中药网**（kmzyw.com.cn）—— 菊花类六个市场比价，放在页面最底下
- **康美历史价格**（kmzyw.com.cn/jiage）—— 点行弹出的那条曲线，逐日采集。**站方免费只给最近一年**，十年以上是付费数据，没有免费入口

三个都是行业里认的公开行情站，不是编的。

**大表每天刷，曲线一个月刷一次就行**（价格天天变，历史不会天天改）。要更新曲线：双击 `更新历史曲线.bat`，等两三分钟。

## 四、几句实在话

**这个表不能当买卖依据。** 它告诉你「市场上别人挂什么价」，不告诉你「你今天能卖多少」。真正的成交价在你爸的电话里。

**同品种不同规格，价差能翻倍。** 贡菊朵菊 100，亳菊统货 25，都是菊花——差别在等级和产地。报价前一定问清规格，别拿统货价对人家精选货。

**看到涨也别急着等。** 行情涨了你手里的货才值钱，但涨完会跌。落袋为安这四个字，在这行比在任何行都硬。

**报价和成交是两回事。** 表上 100 元/公斤，是商家挂牌价。你一次出五吨，人家给你 85 也很正常。

## 六、在手机上看

电脑开着的时候，手机也能看这张表，同一个 WiFi 就行。

**怎么弄：**

1. 双击 **手机上看.bat**
2. 会跳出一个黑窗口，上面写着两行地址，挑一行，比如 `http://192.168.1.7:7788`
3. 手机连上**跟电脑同一个 WiFi**
4. 手机浏览器打开那个地址——**别用微信打开，微信会拦**
5. 打开后点浏览器菜单里的「添加到主屏幕」，以后一点就进，跟装了个 App 一样

第一次运行，Windows 可能弹一个防火墙提示，点「允许访问」，不然手机连不进来。

**手机上长什么样：**

- 大表变成两行：品名和规格在左边，价格、月涨跌、年涨跌在右边
- **点任意一行，价格曲线全屏弹出来**，跟电脑上一样能切规格、切区间
- 搜索框还在，能搜「菊花 亳州」这种组合

**几个要注意的：**

- 那个黑窗口**不能关**，关了手机就打不开了
- 电脑关机、睡眠、或者断了网，手机也就打不开了
- 换了 WiFi（比如从家搬到店里），地址会变，重新双击「手机上看.bat」看新地址
- 想长期不靠电脑，得把表传到网上去，那是另一件事，现在这个不是

## 七、出问题了

**抓取失败**：多半是网络或对方网站临时抽风。等十分钟再试，或者先用「快刷测试.bat」。

**页面空白**：文件被移动了，或者 data 文件夹删了。把整个文件夹一起挪，别只挪 html。

**想加品种**：用记事本打开 `fetch-price.mjs`，找到最上面 `const FOCUS = [` 那一段，把品种名加进去（照格式，"黄芪", 这样）。改完保存，重新刷新就有了。
