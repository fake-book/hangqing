# 上云 · 照这个做

> 目标：手机上点开就能看，**跟你家电脑开不开机没关系**，地址永不变。
> 代价：一年 99 元左右 + 实名认证。这是目前最省事的一条路。

---

## 先说清楚一件事

你现在地址每次变，**不是缺域名，是缺一台 24 小时不关的机器**。

- 域名是"门牌号"，服务器是"房子"。
- 没房子，门牌号挂了也没人住。
- 有了房子（云服务器），**它的 IP 天生就是固定的**，连域名都不需要。

所以顺序是：**先买服务器，域名以后想加再加。**

---

## 第一步：买服务器（约 10 分钟）

### 买哪个

| 商家 | 配置 | 大概价格 | 备注 |
|---|---|---|---|
| 阿里云 轻量应用服务器 | 2核2G / 3M带宽 / 40G盘 | 新用户 99 元/年 | [价格表](https://developer.aliyun.com/article/1768012#1) |
| 腾讯云 轻量应用服务器 | 2核2G / 4M带宽 / 40G盘 | 新用户 99 元/年（学生更便宜） | [学生机政策](https://www.atengyun.com/3318.html) |

**记住三件事**：

1. **镜像选 `Ubuntu 22.04`**（不要选 CentOS，不要选 Windows——Windows 版更贵，而且你不需要）
2. **地区随便选**，选离安徽近的（上海 / 杭州 / 南京）延迟低
3. **带宽 3M 够用**——这个页面 0.6 MB，3M 带宽打开大概 2 秒

### 买完你会拿到

- 一个**公网 IP**，长得像 `47.98.123.45` ← 这就是你以后固定不变的地
- 一个 root 密码（或密钥）

### 实名认证

国内服务器必须实名（身份证 + 人脸）。绕不过，但一次就完事。

> **不用备案。** 备案只管「域名 + 80/443 端口」。你用 IP + 7788 端口，直接能用。

---

## 第二步：放行 7788 端口（关键，很多人卡在这）

服务器默认只开 22/80/443，**7788 要手动开**，不然手机打不开。

### 阿里云
控制台 → 轻量应用服务器 → 点你的服务器 → **防火墙** → 添加规则：
- 应用类型：自定义
- 协议：TCP
- 端口范围：`7788`
- 授权对象：`0.0.0.0/0`

### 腾讯云
控制台 → 轻量应用服务器 → 点服务器 → **防火墙** → 添加规则：
- 协议端口：`TCP:7788`
- 来源：`0.0.0.0/0`

---

## 第三步：把文件传上去

### 方法一（推荐，网页操作不用装软件）

1. 服务器控制台 → 点你的服务器 → **远程连接**（阿里云叫 Workbench，腾讯云叫 OrcaTerm）
2. 登录进去（要输 root 密码）
3. 远程连接窗口里一般有个 **「文件」/「上传」** 按钮，把电脑上的 **`行情表-上云包.zip`** 拖上去
4. 传到 `/root/` 目录下

### 方法二（如果上面找不到上传按钮）

在远程连接的终端里直接下（把 zip 先发到自己微信/邮箱，用直链）：

```bash
cd /root
wget -O 上云包.zip "你的下载链接"
```

---

## 第四步：解压 + 一条命令装完

在远程连接的终端里，**复制下面这四行，粘贴，回车**：

```bash
cd /root
apt-get update -y && apt-get install -y unzip
unzip -o 上云包.zip -d /root/hangqing
cd /root/hangqing && bash deploy.sh
```

`deploy.sh` 会自动做这些事（你不用管）：

1. 装 Node.js 20（走国内镜像 `registry.npmmirror.com`，不用翻墙，约 1 分钟）
2. 用 pm2 把服务挂起来（**关机重启也会自动起来**）
3. 设一个定时任务：**每天早上 8:30 自动抓最新行情**
4. 打开 7788 端口（ufw / firewalld 两道都处理）
5. 最后打印一行 `http://你的IP:7788`

看到那行地址，就成了。

---

## 第五步：手机上打开

1. 手机浏览器输入 `http://你的公网IP:7788`
2. 打开后 → 菜单 → **「添加到主屏幕」**
3. 桌面上就有个图标，以后点它就开，跟 App 一样

> 用 Edge / Chrome / 夸克 打开能"添加到主屏幕"；微信里打开只能看，装不了图标。

---

## 以后怎么更新

**不用管。** 每天早上 8:30 自动抓一次。

### 想立刻手动更新一次

```bash
cd /root/hangqing && node fetch-price.mjs
```

### 想更新历史曲线（一个月一次就够）

```bash
cd /root/hangqing && node fetch-history.mjs && node fetch-price.mjs --rebuild
```

### 想改自动更新时间

```bash
crontab -e
# 把 30 8 * * * 改成你要的时间，比如 0 7 * * * 就是早上 7 点
```

## 出问题怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 电脑能开，手机打不开 | 7788 端口没放行 | 回到第二步，检查防火墙规则 |
| 打开是空白/超时 | 服务没起来 | `pm2 status` 看是不是 online；不行就 `pm2 restart all` |
| 数字一直是昨天的 | 定时任务没跑 | `crontab -l` 看有没有那行；手工跑一次 `node fetch-price.mjs` |
| 想换端口（7788 被占） | — | `set PORT=8899` 改成 `PORT=8899 pm2 restart all`，别忘了防火墙也开 8899 |
| 抓不到数据 | 网站改版了 | 把 `fetch-price.mjs` 发给我，我改 |

## 花了多少钱 / 值不值

- 服务器 99 元/年 ≈ **一天 2 毛 7**
- 换来的是：不用惦记电脑开没开，早上起来手机点开就是昨天的新行情

如果你现在还不想花这 99 块，**先这么用**：

> 电脑不关机、不关那个黑窗口 → 现在那个 `https://xxx.trycloudflare.com` 地址就一直是通的。
> 一旦关机或断网，地址就废了，得重新开一个。

**这就是"临时"和"固定"的区别。**
